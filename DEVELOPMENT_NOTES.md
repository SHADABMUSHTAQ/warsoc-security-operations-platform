# Development notes

## Qoder disclosure

The WarSOC team used Qoder as an AI-assisted development environment during implementation and refinement of this frontend. Team members reviewed the resulting code, tested the shared frontend contracts, and prepared this public submission copy.

## Public-submission boundary

This repository contains the frontend source required to demonstrate the product experience. It deliberately omits backend source code, live deployment values, private reports, generated operational output, and every source-repository commit. The application expects a separately configured compatible backend.
